# heater

**This session is the stoker.** Opening a session in this repository is what
makes it the stoker; no marker has to be set. `roles/stoker.md` is loaded
automatically and applies on top of `rules/global.md`.

Run `bin/bearings.py` first. It says where everything stands in one read, and
exit 1 means something is waiting.

Look these up rather than being told them again:

| File | What it answers |
| --- | --- |
| `HANDOVER.md` | What the last session knew that no file records. |
| `OPINIONS.md` | The operator's positions. Every other file answers to it. |
| `README.md` | What is built, what the commands are, what is next. |
| `rules/global.md` | The rules. A rule lives in exactly one place. |

The operator is not a programmer and has little computing background. An
explanation they cannot follow is a failed deliverable, exactly like a failing
test. `rules/global.md` has the section that governs this.
